# Exercise *Placeholder*: Setting Up Copado Robotic Testing Environment

## Overview
In this exercise, you will confirm access to the Copado Robotic Testing platform, create essential CRT records, and set up your first automated test job using the Webshop Accelerator.

## Learning Objectives
By the end of this exercise, you will be able to:
- Access and navigate robotic.copado.com
- Create and configure a Project record
- Create and configure a Robot record
- Generate a Test Job using the Webshop Accelerator
- Understand the relationship between Projects, Robots, and Test Jobs

## Prerequisites
- Valid credentials for robotic.copado.com
- Completion of all required training modules
- Basic understanding of Copado Robotic Testing concepts

## Exercise Steps

### Step 1: Confirm Access to robotic.copado.com
1. Navigate to [robotic.copado.com](https://robotic.copado.com)
2. Log in using your provided credentials
3. Verify that you can access the main dashboard
4. Familiarize yourself with the navigation menu

**Expected Result:** You should successfully log in and see the CRT dashboard.

---

### Step 2: Create a Project Record (Instructor-Led)
**Note:** Your instructor will create one shared Project and provide access to all participants.

1. Navigate to **Projects** in the main menu
2. Click **New Project**
3. Enter the following details:
   - **Project Name:** `[Your Project Name]`
   - **Description:** `Shared training project for CRT exercises`
4. Click **Save**
5. Configure project settings as needed
6. Share access with all training participants

**Expected Result:** A new Project record is created and visible to all participants.

---

### Step 3: Create Your Personal Robot Record
Each participant will create their own Robot for test execution.

1. Navigate to **Robots** in the main menu
2. Click **New Robot**
3. Enter the following details:
   - **Robot Name:** `[YourName]_Robot` (e.g., `JohnDoe_Robot`)
   - **Project:** Select the shared project created in Step 2
   - **Description:** `Personal robot for training exercises`
4. Configure robot settings:
   - **Type:** Select appropriate robot type
   - **Environment:** Select your target environment
5. Click **Save**
6. Note your Robot ID for future reference

**Expected Result:** Your personal Robot record is created and linked to the shared Project.

---

### Step 4: Create a Test Job Using the Webshop Accelerator
The Webshop Accelerator provides pre-built test scenarios to help you get started quickly.

1. Navigate to **Test Jobs** in the main menu
2. Click **New Test Job**
3. Select **Use Accelerator**
4. Choose **Webshop Accelerator** from the available options
5. Configure the Test Job:
   - **Test Job Name:** `[YourName]_Webshop_Test` (e.g., `JohnDoe_Webshop_Test`)
   - **Project:** Select the shared project
   - **Robot:** Select your personal robot created in Step 3
   - **Description:** `Webshop test job for training`
6. Review the pre-configured test steps provided by the accelerator
7. Click **Save**

**Expected Result:** A new Test Job is created using the Webshop Accelerator template.

---

### Step 5: Verify Your Setup
1. Navigate to your Project record
2. Verify that your Robot appears in the associated Robots list
3. Verify that your Test Job appears in the associated Test Jobs list
4. Review the hierarchy: Project → Robot → Test Job

**Expected Result:** All records are properly linked and visible within the Project.

---

## Troubleshooting

### Cannot Access robotic.copado.com
- Verify your credentials are correct
- Check with your instructor to confirm your account has been provisioned
- Clear browser cache and try again

### Cannot See the Shared Project
- Confirm the instructor has shared access with you
- Refresh the Projects page
- Check your user permissions

### Robot Creation Fails
- Ensure you've selected the correct Project
- Verify all required fields are completed
- Check that your Robot name is unique

### Webshop Accelerator Not Available
- Confirm you have the necessary permissions
- Verify the accelerator is enabled for your organization
- Contact your instructor for assistance
